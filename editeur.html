Aperçu du fichier RDVCitoyens.xml

Ce texte se met à jour automatiquement et respecte le format XML d'origine. Pour mettre à jour le site (AEM), utilisez le bouton « 📋 Copier le bloc de données » en haut : il enveloppe ce XML dans la balise attendue, prête à remplacer intégralement le contenu du composant COLI n°2 (fichier coli-2-donnees.html). Les boutons « Copier le XML » / « Télécharger » servent à garder ou partager le fichier RDVCitoyens.xml lui-même, séparément.
